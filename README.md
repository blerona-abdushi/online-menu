🍽️ Online Menu

Online Menu is a full-stack restaurant order management platform, designed to simplify the ordering process and food management. The application uses a role-based login system, where each user — customer, chef, staff or manager — has different access and views appropriate to the functions they need.


✨ Key Features

👤 Role-based login: each user sees a personalized view based on their role

Customer: can view the menu and place orders

Chef: can monitor and prepare orders

Staff: can assist in preparing and serving orders

Manager: can monitor all orders and manage users

🛒 Order online: customers can select food and place orders in an organized manner

📊 Role dashboard: each user has a view that reflects their tasks

🛠️ Technologies used

Frontend: React.js

Backend: Node.js with Express.js

Database: PostgreSQL for storing user and order data
